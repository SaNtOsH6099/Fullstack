# ReactJS - Hello World

A basic Hello World React application built with React and Vite.

## Live deployment here :

[ https://santosh6099.github.io/Fullstack/React/02-hooks/](https://santosh6099.github.io/Fullstack/React/02-hooks/)

## Features

- Proper comments
- Renders shoes data when added in data array
- Add item to cart button
- Increase or decrease quantity buttons in the cart
- updates total dynamically.

## Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)

## Installation

1. Install dependencies:

```bash
npm install
```

## Running the Application

To start the development server:

```bash
npm run dev
```
